`Fullstack: Node.js, Express, React 19, Vite 8, Tailwind CSS 4, MySQL, Sequelize, Docker`
* **Pasarela de pagos real:** Integración con Mercado Pago (Checkout Pro) y procesamiento de notificaciones de pago en tiempo real mediante Webhooks.
* **Asistente virtual con IA:** Chatbot potenciado por Groq (Llama 3) conectado al catálogo en vivo, con búsqueda optimizada, *fallback* local y endpoints para automatizaciones externas (n8n / Make).

* **Monitoreo Wi-Fi en segundo plano ("Modo Guardián"):** Detección automática de llegadas y salidas de zonas seguras mediante *Foreground Services*, *WorkManager* y `BootReceiver` nativo.
* **Backend SaaS multi-usuario:** API en FastAPI con autenticación JWT, control anti-duplicados de eventos, dashboard web administrativo y envío instantáneo de alertas personalizadas vía Telegram Bot API (sincronizadas en UTC-3).

* **Entrenamiento activo en vivo:** Selector táctil de discos y repeticiones sin teclado, referencia de *"la última vez"* para sobrecarga progresiva, cronómetro continuo y temporizador de descanso automático con respuesta háptica (`expo-haptics`).
* **Analítica y evolución física:** Calendario mensual de constancia, gráficos de progresión por ejercicio, cálculo de 1RM estimado (fórmula Epley), récords personales (PR) y módulo de seguimiento de peso corporal.
